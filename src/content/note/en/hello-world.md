# Hello World

Welcome to my new blog! This is my first post using Nextra, a powerful static site generator built on top of Next.js.

## What is Nextra?

Nextra is a simple, powerful and flexible site generation framework with everything you love from Next.js. It allows you to write content in MDX format, which means you can use both Markdown and React components in your posts.

## Features I Love

- **Fast**: Built on Next.js with SSG (Static Site Generation)
- **Flexible**: Write in MDX format
- **Dark Mode**: Built-in dark mode support
- **Responsive**: Mobile-friendly out of the box
