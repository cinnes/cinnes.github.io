## Projects

Here are some of the projects I've been working on. From open source contributions to personal experiments, each project has taught me something new about web development.

### Featured Projects

#### Personal Blog
A modern blog built with Astro and ThoughtLite theme, featuring:
- Static site generation for optimal performance
- Dark/light theme switching
- Full-text search functionality
- RSS feed support
- Responsive design

**Tech Stack:** Astro, TypeScript, Svelte, UnoCSS

#### Task Management App
A productivity application for managing daily tasks and projects:
- Real-time updates with optimistic UI
- Drag-and-drop interface
- Team collaboration features
- Offline-first architecture

**Tech Stack:** React, TypeScript, Node.js, PostgreSQL

#### Component Library
A reusable component library for React applications:
- Fully typed with TypeScript
- Comprehensive Storybook documentation
- Automated testing with Jest and Testing Library
- Design system integration

**Tech Stack:** React, TypeScript, Storybook, Jest
