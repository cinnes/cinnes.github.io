# Web Performance Optimization in 2024

## Core Web Vitals Overview

Google's Core Web Vitals are essential metrics for measuring user experience:

### 1. Largest Contentful Paint (LCP)
- **Target**: < 2.5 seconds
- **Measures**: Loading performance
- **Tips**: Optimize images, use CDN, implement preloading

### 2. First Input Delay (FID)
- **Target**: < 100 milliseconds  
- **Measures**: Interactivity
- **Tips**: Minimize JavaScript, use web workers, optimize third-party scripts

### 3. Cumulative Layout Shift (CLS)
- **Target**: < 0.1
- **Measures**: Visual stability
- **Tips**: Set image dimensions, avoid inserting content above existing content

## Modern Optimization Techniques

### Image Optimization

Use next-generation formats and responsive images:

```html
<picture>
  <source srcset="hero.avif" type="image/avif">
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Hero image" loading="lazy" />
</picture>
```

### Critical Resource Hints

Optimize resource loading with hints:

```html
<!-- Preload critical resources -->
<link rel="preload" href="/fonts/main.woff2" as="font" type="font/woff2" crossorigin>

<!-- Prefetch likely next-page resources -->
<link rel="prefetch" href="/about">

<!-- Preconnect to external domains -->
<link rel="preconnect" href="https://fonts.googleapis.com">
```

### JavaScript Optimization

#### Code Splitting
```javascript
// Dynamic imports for lazy loading
const LazyComponent = lazy(() => import('./LazyComponent'));

// Route-based splitting
const Home = lazy(() => import('./pages/Home'));
const About = lazy(() => import('./pages/About'));
```

#### Tree Shaking
```javascript

// Instead of

```

## Performance Monitoring

### Real User Monitoring (RUM)

```javascript
// Web Vitals measurement
import { getCLS, getFID, getFCP, getLCP, getTTFB } from 'web-vitals';

function sendToAnalytics(metric) {
  // Send to your analytics service
  gtag('event', metric.name, {
    value: Math.round(metric.value),
    event_category: 'Web Vitals',
  });
}

getCLS(sendToAnalytics);
getFID(sendToAnalytics);
getFCP(sendToAnalytics);
getLCP(sendToAnalytics);
getTTFB(sendToAnalytics);
```

### Performance Observer API

```javascript
// Monitor long tasks
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    if (entry.duration > 50) {
      console.warn('Long task detected:', entry);
    }
  }
});

observer.observe({ entryTypes: ['longtask'] });
```

## Advanced Strategies

### Service Workers for Caching

```javascript
// sw.js
const CACHE_NAME = 'v1';
const urlsToCache = [
  '/',
  '/static/css/main.css',
  '/static/js/main.js'
];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then((cache) => cache.addAll(urlsToCache))
  );
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request)
      .then((response) => response || fetch(event.request))
  );
});
```

### HTTP/2 and HTTP/3 Benefits

- **Multiplexing**: Multiple requests over single connection
- **Server Push**: Proactively send resources
- **Header Compression**: Reduced overhead
- **Binary Protocol**: More efficient parsing
