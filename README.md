# Personal Blog

My personal blog built with Next.js and TypeScript.

## What's Here

- Blog posts about web development and programming
- Search and filtering functionality
- Responsive design

## Tech Stack

- Next.js 15 with TypeScript
- Tailwind CSS for styling
- Nextra for documentation
- Jest for testing

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Adding Posts

Edit the `sampleBlogPosts` array in `lib/blogData.ts` to add new blog posts.
